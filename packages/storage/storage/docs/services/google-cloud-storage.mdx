# Google Cloud Storage

> **Just need ad-hoc uploads?** Wrap this adapter in the [`Files` facade](../files-facade.mdx) for a one-liner API. The reference below shows direct adapter usage — pick that path when you're hosting an upload server.

## Overview

Google Cloud Storage is a unified object storage for developers and enterprises, from live data serving to data analytics/ML to data archiving. It integrates seamlessly with Visulima upload's image transformation capabilities.

## Usage

```ts
import { Files } from "@visulima/storage";
import { LRUCache } from "lru-cache";
import { GCStorage } from "@visulima/storage/provider/gcs";
import ImageTransformer from "@visulima/storage/transformer/image";

const storage = new GCStorage({
    bucket: "upload",
    projectId: "test",
    maxUploadSize: "1GB",
    logger: console,
    expiration: { maxAge: "1h", purgeInterval: "15min" },
});

// Initialize cache for transformed images
const cache = new LRUCache({
    max: 1000, // Maximum number of cached items
    ttl: 3600000, // 1 hour in milliseconds
});

// Initialize image transformer for on-demand transformations
const imageTransformer = new ImageTransformer(storage, {
    cache,
    maxImageSize: 10 * 1024 * 1024, // 10MB
    cacheTtl: 3600, // 1 hour
});

// Upload a file (the key doubles as the file id)
const files = new Files({ adapter: storage });

await files.upload("image.jpg", fileBuffer, { contentType: "image/jpeg" });

// Transform the uploaded image
const thumbnail = await imageTransformer.resize("image.jpg", {
    width: 300,
    height: 200,
    fit: "cover",
    quality: 80,
});
```

## Image Transformations

Google Cloud Storage works seamlessly with Visulima upload's image transformation features:

```ts
// Resize images
const resized = await imageTransformer.resize("file-id", {
    width: 800,
    height: 600,
    fit: "cover",
});

// Convert formats: `transform` takes an array of steps
const webp = await imageTransformer.transform("file-id", [{ type: "format", options: { format: "webp", quality: 85 } }]);

// Or the shorthand
const avif = await imageTransformer.convertFormat("file-id", "avif", { quality: 60 });

// Crop images
const cropped = await imageTransformer.crop("file-id", {
    width: 400,
    height: 300,
    left: 100,
    top: 50,
});
```

## Configuration

| Name          | Type   | Description                               | Default |
| :------------ | :----- | :---------------------------------------- | :------ |
| bucket        | string | The name of the bucket to use             |         |
| projectId     | string | Google Cloud project ID                   |         |
| maxUploadSize | string | Maximum upload size (e.g., "1GB", "10MB") |         |
| expiration    | object | File expiration configuration             |         |
| logger        | Logger | Logger instance                           |         |

## Performance Considerations

1. **Global CDN**: GCS automatically serves files through Google's global CDN
2. **Caching**: Enable transformation caching to reduce processing overhead
3. **Private files**: `GCStorage` does not implement `getReadUrl()` / `getUploadUrl()`; serve private files through your upload handler's `GET` route
4. **Lifecycle Policies**: Configure automatic cleanup of temporary transformations

## Signed URLs

`GCStorage` does not implement `getReadUrl()` or `getUploadUrl()`, so `files.url()` and `files.signedUploadUrl()` reject with `METHOD_NOT_ALLOWED`. Serve private files through your upload handler's `GET` route (or a `MediaTransformer` for transformed variants). If you need V4 signed URLs on a Google Cloud bucket, the [Firebase adapter](./firebase.mdx) implements both.
