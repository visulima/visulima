# Installation

```bash npm2yarn
npm install @visulima/cron-parser
```

## Entry points

| Import                             | Use it for                                                                          |
| ---------------------------------- | ----------------------------------------------------------------------------------- |
| `@visulima/cron-parser`            | The default API. Runs on Node.js, Deno, Bun and Cloudflare Workers.                 |
| `@visulima/cron-parser/cloudflare` | The default API with `dialect: "cloudflare"` applied, for Cloudflare Cron Triggers. |
| `@visulima/cron-parser/file`       | Reading a crontab file. It needs `node:fs`, so it is kept out of the other entries. |

```ts
import { parse } from "@visulima/cron-parser";
```
